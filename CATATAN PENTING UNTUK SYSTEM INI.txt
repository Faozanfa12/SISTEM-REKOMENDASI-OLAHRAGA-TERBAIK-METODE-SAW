# 1. Buat proyek Laravel 11 baru
composer create-project laravel/laravel spk-saw-lansia

# 2. Masuk ke direktori
cd spk-saw-lansia

# 3. Instal UI bawaan (Bootstrap 5)
composer require laravel/ui
php artisan ui bootstrap --auth

# 4. Instal NPM dependencies & build
npm install
npm run dev harus dijalankan
php artisan serve untun running program

# 5. Atur file .env Anda

# 6. Jika Anda mengganti nama folder lagi — langkah pencegahan / cara perbaikan cepat

Setelah mengganti nama folder proyek, jalankan ulang pembuatan link storage agar junction menunjuk ke lokasi yang benar:
PowerShell (jalankan terpisah, satu per satu):

Remove-Item "C:\xampp\htdocs\<NAMA_PROYEK>\public\storage" -Recurse -Force
php artisan storage:link

Atau (jika rmdir lebih familiar):

rmdir "C:\xampp\htdocs\<NAMA_PROYEK>\public\storage"
php artisan storage:link

# 7. untuk bikin password yang di hash dan dimasukan ke dalam localserver secara manual tanpa migrasi seeder
